# Qesto — пакет 1: жизненный цикл и фоновая синхронизация банка

Дата: 2026-09-08. Локальная Windows-версия: **1.0.38+39**.

## Причина и исправления

- Возврат в приложение запускал полную загрузку данных и пересоздавал владельца финансового контроллера/планировщика. Открытый маршрут банка мог остаться со старым, уже disposed менеджером и показать ложное «уже выполняется». Теперь resume обновляет только публичные предложения; финансовый контроллер, браузерный маршрут и блокировка сохраняют одного владельца. Ошибка обновления предложений не разрушает рабочую сессию.
- Фон использует существующий SberConnector и тот же импорт через Synoball, без второго парсера. Интервал — час с разбросом 54–66 минут; минимум после успешной синхронизации — 45 минут. Старая трёхчасовая будущая задача переносится на почасовой график без немедленной серии запросов. После сна выполняется одна просроченная задача, а не каждая пропущенная.
- В фоне разрешён существующий ограниченный сценарий быстрого входа по сохранённому PIN. При отсутствующем PIN, неподтверждённом входе или полном логине возвращается authRequired: автоматические повторы останавливаются. После подтверждённой авторизованной страницы при закрытии видимого браузера расписание возобновляется; сам вход не засчитывается как успешный импорт.
- PIN хранится отдельно для каждого CEF-профиля в защищённом хранилище. Старый общий PIN переносится только при единственном профиле Сбера. При нескольких профилях следует сохранить PIN отдельно в карточке нужного подключения; код другого профиля не используется.
- Отмена/таймаут/dispose немедленно отзывают право позднего финансового импорта и вызывают закрытие соответствующего браузера. Блокировка не снимается, пока исходная задача действительно не завершилась. Ошибка или истечение срока закрытия не разрешают параллельный запуск поверх старого браузера.
- Нативный close отвечает только после CEF OnBeforeClose. Закрытие во время create дожидается выделенного браузера и закрывает его; позднее завершение create не оживляет закрытый контроллер. Ожидания загрузки/перехода прерываются при close. Быстрый onLoadEnd не затирается состоянием «загружается», а запрос кнопок навигации ждёт готовности оболочки.
- Клавиатура/IME направляются только браузеру с запрошенным Flutter-фокусом. Диалоги Qesto и скрытый браузер не используют оставшийся DOM-фокус страницы. Обработчики и текстовый клиент снимаются при удалении виджета.

## Границы результата

- Схема Synoball, категоризация, расчёт cash flow и правила извлечения банковских операций в этом пакете не менялись. Предыдущие незакоммиченные изменения аудита сохранены.
- Фон работает, пока процесс Qesto запущен (в том числе свёрнут). Windows-служба, синхронизация при полностью закрытом приложении и сервер здесь не создавались.
- Зависший нативный процесс намеренно не объявляется успешно остановленным. При отсутствии подтверждения закрытия новая работа блокируется; принудительное завершение процесса не выполняется.
- Полноценный живой цикл с истёкшей банковской сессией, автоматическим PIN, сбором истории и следующим часовым запуском нельзя считать доказанным только тестами/сборкой. Для этого требуется проверка в авторизованном профиле пользователя; ввод секретов и обход банковских проверок агентом не выполнялись.
- Это локальная тестовая сборка, не подписанный публичный релиз. Git commit/push в рамках этого запроса не выполняются.
