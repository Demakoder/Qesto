# Qesto / Synoball — проект межустройственной синхронизации

Дата: 08.10.2026. Статус: **предложение для согласования, не реализация**.

## Рекомендация в одном абзаце

Сохранить offline-first поведение и финансовую семантику Synoball. Добавить локальную SQLite-транзакцию «изменение + durable outbox», отдельный HTTPS Sync API и PostgreSQL на сервере. Сервер согласует изменения **тем же ядром Synoball**, а не новым алгоритмом дедупликации. Клиенты получают каноническое состояние и строят аналитику локально. Начать с транзакционного контейнера существующего codec-снимка, без массовой нормализации всех моделей в SQL-таблицы. Это рекомендация; выбор зависимости, авторизации и режима доступа сервера к данным требует отдельного утверждения.

## Ключевые открытия

- Сейчас финансовое хранилище — AES-GCM JSON-снимок, не клиентская SQL-БД. Очередь сохранений и резервная копия полезны, но durable outbox отсутствует.
- `local-user`, `ent-local-user` и некоторые локальные ID не являются глобальной межустройственной identity.
- Synoball уже умеет source evidence, ручные override/locks, повторный импорт и корзину. Его `events` и `FinancialAction` не являются надёжным журналом доставки.
- Банковский баланс хранится отдельно от операций. Повторная доставка операции не должна повторно менять баланс; графики, Cash Flow и recurring пересчитываются из первичных данных.
- Существующий Python/SQLite backend обслуживает публичные предложения, а не приватные финансовые данные и авторизацию Qesto.

## Что проверено

Запущены девять существующих test-файлов: **63 теста прошли**. Сверены SHA-256 361 исходного/config-файла из `lib`, Android sources, Windows runner, `services`, `pubspec.yaml/lock` и Android build config: отличий от начала исследования нет. Тесты подтверждают только текущие локальные механизмы, не предлагаемый Sync API. Новая синхронизация ещё не существует и не тестировалась на двух устройствах.

`AGENTS.md` и `QESTO_AI_DEVELOPMENT_PROTOCOL_v0.1` в проверенных путях репозитория/его родителей не найдены; специфические требования отсутствующего документа не выдумывались.
