# Qesto typography fonts

Qesto permanently uses typography variant B. Font binaries are self-hosted and
are not fetched at runtime. The accompanying OFL files are preserved here.

| Family | Source | Asset |
| --- | --- | --- |
| Manrope | https://github.com/sharanda/manrope | `assets/fonts/manrope` |
| IBM Plex Sans / Mono | https://github.com/IBM/plex | `assets/fonts/ibm_plex` |

The distributed binaries were taken from the official upstream repositories.
On 2026-08-14 every retained binary was inspected with fontTools: Russian
Cyrillic, `₽`, `$`, `€`, `%`, plus/minus, punctuation and digits are present.
