# Qesto

Flutter-приложение Qesto для Windows, Web и Android. Все финансовые источники
нормализуются в единое ядро Synoball.

## Что уже работает

- вкладки «Бюджет», «Выгода» и «Накопления» с сохранением состояния;
- месяцы бюджета, лимит, интерактивная диаграмма и список счетов;
- купоны, акции и отслеживаемые товары;
- цели накопления и история финансовых действий;
- состояния загрузки, ошибки и отсутствия данных;
- локальное сохранение пользовательских данных без предзаполненных операций.

На Android банковские уведомления после выдачи системного доступа автоматически
попадают в Synoball: сразу, пока Qesto запущена, либо при следующем запуске/возврате
в приложение. Подтверждение для уверенно распознанной покупки не требуется;
нераспознанные сообщения остаются во входящих и не меняют финансовые данные.

При каждом поступлении уведомления, чека, выписки или API-операции Synoball сначала
ищет уже известное финансовое событие. Стабильный идентификатор источника имеет
приоритет. Эвристическое слияние разрешено только между разными источниками при
точном совпадении суммы, валюты и направления, а также совместимых продавце и
времени. Слияние дополняет доказательства, счёт, чек и категории; две похожие
операции одного источника без общего идентификатора сохраняются раздельно.

## Запуск в VS Code

1. Откройте терминал в папке `apps/qesto_app`.
2. Выполните `flutter pub get`.
3. Для браузера выполните `flutter run -d edge`.
4. Для выбора другого доступного устройства выполните `flutter devices`, затем `flutter run -d <имя устройства>`.

Если команда `flutter` пока не находится, перезапустите VS Code после добавления Flutter в `PATH` или временно используйте полный путь к `flutter.bat`.

## Desktop-аналитика

Навигация Windows-версии повторяет продуктовую модель Android и разделена на три
верхнеуровневых пространства: «Бюджет», «Выгода» и «Накопления». Внутри бюджета
находятся операции, план, денежный поток, статистика, регулярные платежи, счета и
insights; предложения вынесены в «Выгоду», а цели и капитал — в «Накопления».

Экран денежного потока строится только из пользовательских операций Synoball и
показывает интерактивную реку «доход → категории → крупнейшие покупки», сравнение
с предыдущим периодом, норму сбережений и помесячный чистый поток. Отображение
сумм можно скрыть. На главном экране ритм расходов сопоставляет фактическую и
идеальную скорость расходования бюджета и рассчитывает безопасную сумму на день.

Название, цвет и пиктограмму категории можно менять в плане бюджета. Это
пользовательский слой представления: он сохраняется отдельно и не меняет модель,
нормализацию или контракты Synoball.

Вариант B выбран как постоянная типографика: IBM Plex Sans для заголовков,
Manrope для элементов интерфейса и IBM Plex Mono для числовых данных. Шрифты
self-hosted, а их OFL-лицензии включены в пакет. В профиле доступны системная,
светлая и тёмная темы; выбор оформления сохраняется локально.

Боковая навигация работает как аккордеон: пункты «Бюджет», «Выгода» и
«Накопления» раскрывают только относящиеся к ним экраны. Настройки находятся в
карточке профиля, где можно изменить имя, выбрать условный аватар и основную
валюту. Актуальный справочный курс загружается из официального XML Банка России;
смена основной валюты не переписывает валюту существующих операций Synoball.

Нулевой общий или категорийный план имеет отдельную семантику «бюджет не
назначен». В этом состоянии Qesto показывает фактические расходы, но не считает
процент, превышение, допустимый расход или прогноз относительно нуля. Общий
лимит можно назначить непосредственно на desktop-экране бюджета.

## Windows

Desktop-интерфейс включается автоматически от 900 logical pixels. Запуск:

```powershell
flutter run -d windows
```

В production-сборке нет demo-режима и заранее созданных финансовых данных.
Выписки выбираются системным диалогом Windows и читаются встроенным pure-Dart
PDF parser; Sber-адаптер поддерживает как построчный, так и новый двухколоночный
PDF-шаблон Сбербанка. Универсальный табличный адаптер отдельно от Synoball читает
XLSX/XLSM, распознаёт журналы операций и помесячные матрицы и передаёт результат через
штатную границу импорта; формулы и макросы не выполняются. Фотографии чеков
распознаются локальным Windows OCR, а голосовой
ввод использует встроенный офлайн-модуль whisper.cpp с русской моделью. Запись
не отправляется в облако. Перед проведением голосовой операции Synoball всегда
требует подтверждение. Локальные данные находятся в
`%APPDATA%\Qesto\store.json` и записываются атомарно.

Основная точка входа — `lib/main.dart`. Все данные конкретного пользователя объединены в `UserFinancialData`; категории остаются системным справочником приложения. Интерфейс по функциональным разделам находится в `lib/features`.
