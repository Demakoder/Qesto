# Qesto

Flutter-приложение находится в `apps/qesto_app`. Сервис акций из Telegram и его
локальный API находятся в `services/deals_ingestion` и запускаются вместе с Qesto.
Для загрузки публикаций Telegram на компьютере должен работать VPN.

## Единый запуск

Из корня проекта:

```powershell
.\Qesto.cmd
```

Команда скрыто запускает сервис акций, ожидает готовности API и открывает Qesto в
Edge. Отдельный терминал для парсера больше не нужен. При закрытии Flutter сервис,
запущенный этой командой, тоже завершается.

Также можно открыть раздел **Run and Debug** в VS Code и выбрать конфигурацию
`Qesto (Edge + сервис)`. Перед запуском приложения VS Code автоматически проверит
и запустит сервис.

Для телефона выберите Android-устройство в нижней панели VS Code, затем запустите
`Qesto (Android USB + сервис)`.

Для запуска на конкретном устройстве:

```powershell
.\Qesto.cmd --device <device-id>
```

Для Android-устройства по USB лаунчер автоматически настраивает `adb reverse`,
поэтому приложение обращается к сервису без настройки IP и Windows Firewall.
Если ADB недоступен, сетевой доступ нужно разрешить явно командой
`.\Qesto.cmd --allow-lan --device <device-id>`; используйте её только в доверенной
локальной сети.

Настройка release-подписи, HTTPS и модель защиты описаны в [SECURITY.md](SECURITY.md).
Пофайловый разбор реализации находится в
[docs/SECURITY_IMPLEMENTATION_RU.md](docs/SECURITY_IMPLEMENTATION_RU.md).

## Диагностика

Лог фонового сервиса сохраняется в
`services/deals_ingestion/data/service.log`. Локальная база и лог исключены из Git.

Ручная разовая синхронизация по-прежнему доступна:

```powershell
.\scripts\sync_deals.cmd
```
