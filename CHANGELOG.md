# История изменений

## 1.0.12 (build 13) — 2026-08-18

### Безопасность

- Добавлена обязательная Authenticode-подпись Windows release и проверка
  подписей EXE/DLL, установщика и деинсталлятора.
- Усилена проверка XLSX, внешних ссылок, PDF.js и банковских уведомлений.
- Ограничены сетевые ответы, сообщения, API concurrency и частота запросов.
- Добавлены CSP/HSTS для Web, security invariants, OSV и release workflows.

### Производительность

- Устранён N+1-паттерн при загрузке источников акций: выдача использует два
  SQL-запроса независимо от количества карточек вместо запроса на каждую.
- WAL SQLite настраивается один раз при инициализации, а счётчики API читаются
  одним запросом.
- Размеры Telegram/MAX ограничиваются до дорогостоящей нормализации и поиска
  ссылок; повторно используемые регулярные выражения компилируются один раз.

### Проверка качества

- Добавлены регрессионные тесты для новых security/performance-инвариантов.
- Обновлена документация по безопасной сборке и публикации.
